# Data

Dataset: **Telco Customer Churn** (IBM sample dataset, ~7,043 customers, 21 columns)

1. Download it from Kaggle: search "Telco Customer Churn" (blastchar/telco-customer-churn).
2. Save the file as `data/raw/WA_Fn-UseC_-Telco-Customer-Churn.csv`.
3. Run the scripts in `src/` (see the main README).

The raw CSV is git-ignored. Cleaned data is written to `data/processed/`.
